# IKE Travel Tracker

A local application for marking visited and planned places on a world map. Includes a travel journal, achievements, and themed challenges. The interface runs in your browser, and your data is saved in CSV files on your device.

## Running on Windows

Extract the entire folder from `Tracker-Wyjazdow-Windows.zip` and open `Tracker Wyjazdow.exe`. The application opens the map in your default browser.

## Notes

An internet connection is required for external map layers and street maps.
